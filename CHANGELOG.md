# Changelog

## 0.1.0-dev.1

First version.

- `Anatomy` component: describes the server-rendered component tree below it, for requests that ask.
- In-page overlay: 2D outlines, 3D layers with or without the page's own pixels, and a panel with tree, inventory and reuse findings.
- `inspect` command: component tree, inventory and repeated-markup findings for one or more pages of a running app, as Markdown or JSON.
- `scan` command: component classes and their construction sites, read from source.
- `skills/jaspr-anatomy` for coding agents.
- Requires Jaspr 0.24.0-beta.0 or later in the 0.24 line and Dart 3.13.
